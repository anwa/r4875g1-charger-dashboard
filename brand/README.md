# Dashboard branding

This directory contains repository branding for the R4875G1 Charger Dashboard.

Files:

- `icon.png` — 256 x 256 PNG, square icon
- `logo.png` — 768 x 256 PNG, landscape logo

The assets are project-specific dashboard branding and intentionally do not use Home Assistant branded artwork.

The README references `logo.png` through an absolute raw GitHub URL so that HACS can render it outside the normal repository-relative context.
